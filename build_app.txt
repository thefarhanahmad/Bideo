### 0. Version Management (Automatic Synchronization)
The Android build system now automatically reads `versionName` and `versionCode` 
directly from `app.json`!

Current Version:
  • Version Name : 1.0.7
  • Version Code : 16  (Previous Play Store release was 15 / 1.0.6)

To automatically bump version for a new release in the future:
  Open terminal in `D:\Bideo\bideoApp` and run:
    npm run version:bump
  (This automatically increments the patch version e.g. 1.0.6 -> 1.0.7 and versionCode 14 -> 15)

  Or specify a custom version:
    node scripts/bump-version.js 1.1.0 15

### 1. Build Local Release APK (For Testing on Physical Android Device)

Open PowerShell in `D:\Bideo\bideoApp`:
  npm run build:apk

Or navigate to android directory:
  cd D:\Bideo\bideoApp\android
  .\gradlew assembleRelease

│ Where to find the generated APK:
│ D:\Bideo\bideoApp\android\app\build\outputs\apk\release\app-release.apk

To install on a connected Android phone via ADB:
  adb install -r D:\Bideo\bideoApp\android\app\build\outputs\apk\release\app-release.apk

--------------------------------------------------------------------------------

### 2. Build Google Play Store Bundle (.aab) (For Play Store Upload)

Open PowerShell in `D:\Bideo\bideoApp`:
  npm run build:aab

Or navigate to android directory:
  cd D:\Bideo\bideoApp\android
  .\gradlew bundleRelease

│ Where to find the Google Play .aab file:
│ D:\Bideo\bideoApp\android\app\build\outputs\bundle\release\app-release.aab

Upload this `.aab` file directly to Google Play Console → Production / Internal Testing.

--------------------------------------------------------------------------------

### 3. Clean Build (Run only if you encounter cache or native build issues)

In `D:\Bideo\bideoApp`:
  npm run build:clean

Or in `android` directory:
  cd D:\Bideo\bideoApp\android
  .\gradlew clean
