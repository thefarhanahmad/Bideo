## 4b. Stop bot farming (found 29 Oct 2026)

A Python script (`python-requests` in the nginx logs) has been hitting the API since 26 Oct,
~10,000 requests a day, still running on 29 Oct. In 26–29 Oct it made 44 accounts, 7,613 views,
7,597 watch-time calls, 1,655 likes, 700 ad-reward claims and 425 uploads (57 got through).
It only uses normal API endpoints that trust what the caller says:
- **Signup** needs only a name, password and any 10-digit phone number, no SMS code
  (`controllers/auth.js` `signupWithPhone`); the signup limiter counts only failed attempts
  (`skipSuccessfulRequests: true` in `middlewares/security.js`)
- **Ad reward** (`/api/boost/claim-ad-reward`) gives 1–6 coins when the app *says* an ad was watched
- **Watch time** (`/api/videos/:id/watch-time`) gives 1 coin per call (every 45 s per video), no check the video played
- **Uploads** trust the file type and name the uploader sends, so PDFs/images labelled `video/mp4`
  get in; the length is also taken from the uploader (`controllers/video.js` `readDurationSeconds`)
- General API limit is 10,000 requests per 15 minutes per client

Already done (29 Oct): removed 54 spam uploads (PDFs labelled as Shorts, titled `topernote….pdf`,
and one `sattaking.org` gambling upload).
